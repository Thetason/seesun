# Marketing Refactor Brief

Last updated: 2026-04-03

This is the single source of truth for the next SEE:SUN marketing-site refactor.
If another AI or developer touches the public site, follow this brief first.

## 1. Goal

Increase:

- `무료 보컬 진단` starts
- diagnosis completions
- consultation conversions into Kakao chat

Do not optimize for abstract luxury branding first.
Optimize for understanding, trust, and action.

## 2. Primary audience

Main audience:

- serious adult vocal learners in Korea
- hobby learners who do not want casual, low-commitment teaching
- people frustrated by:
  - blocked high notes
  - throat tension
  - unstable breathing
  - lesson-room success but real-world collapse
  - lack of clear practice structure

This site is not for:

- one-tip high-note seekers
- casual trial-class visitors
- users who want comfort without practice

## 3. Core positioning

SEE:SUN is:

- not a generic vocal academy
- not a vague luxury art brand
- a serious adult voice conditioning studio

Main promise:

`취미라도 제대로. 노래할 수 있는 몸부터 다시 만듭니다.`

## 4. Product hierarchy

The site must stop presenting all programs with equal weight.

Priority:

1. `시그니처` = main offer
2. `스파크` = lower-friction entry
3. `리저브` = premium private solution for clear short-term goals

Home must sell `시그니처` first.
`스파크` and `리저브` appear later as alternative tracks.

## 5. Messaging rules

Keep:

- premium tone
- minimal palette
- restraint
- seriousness

Remove or reduce:

- manifesto-first copy
- abstract luxury-first language
- internal jargon without translation
- superiority tone

Do not lead with phrases like:

- `예술의 가치를 아는 당신`
- `가치 있는 것은 아무나 얻을 수 없습니다`
- `퀀텀 점프`
- `압도적 성장`
- `주변을 압도하는`

Use more of:

- `컨디셔닝`
- `재세팅`
- `안정감`
- `기록`
- `변화`
- `기준`

## 6. D.A.P. rule

D.A.P. should not read like internal philosophy.

It must be explained as:

- a 4-step practical process
- tied to customer outcomes
- translated into plain language

Each step must answer:

- what changes
- what gets easier
- why it matters in real singing situations

## 7. CTA rule

Use one main CTA across the public site:

- `무료 보컬 진단 받기`

Use one secondary CTA where needed:

- `시그니처 자세히 보기`

Do not mix these labels randomly:

- `무료 보컬컨설팅`
- `레슨문의`
- `보컬 진단 시작`
- `상담 연결`

Naming must be consistent.

## 8. Proof rule

The site currently lacks enough proof.
The refactor must include proof structure even if some content is placeholder content for now.

Proof section types:

- before/after voice comparison
- growth archive
- real student reviews

If real proof is not ready yet, placeholders are acceptable, but the layout must be ready for admin content later.

## 9. Public-site structure

Keep routes:

- `/`
- `/studio`
- `/signature`
- `/reserve`
- `/diagnosis`

Top nav should become:

- 프로그램
- D.A.P.란
- 변화 사례
- 코치 소개
- FAQ
- 무료 보컬 진단 받기

Do not put `리저브` in the primary nav as equal to the main funnel.

## 10. Page roles

### `/`

Role:

- conversion landing page for Signature

Must do:

- identify problem fast
- clarify who this is for
- explain why SEE:SUN is different
- explain D.A.P. simply
- present Signature as the main starting point
- show proof
- send users to diagnosis

### `/studio`

Role:

- sell Spark as structured daily training for people not ready for Signature

### `/signature`

Role:

- strongest sales page on the site
- main offer page

### `/reserve`

Role:

- discreet premium page for short-term, high-stakes, private performance goals

### `/diagnosis`

Role:

- real working 3-minute diagnosis funnel
- recommend Spark, Signature, or Reserve
- convert into Kakao consultation flow

## 11. Immediate priorities

Do these first:

1. Refactor homepage structure and hero message
2. Make diagnosis page fully functional in production
3. Rewrite D.A.P. into customer language
4. Add proof section structure
5. Standardize CTA labels

Do these after:

6. Rewrite Spark page
7. Rewrite Signature page
8. Rewrite Reserve page
9. Clean nav / utility links / footer CTA behavior

## 12. Non-goals

Do not:

- turn the site into a loud growth-hacking landing page
- overuse fake scientific claims
- imply medical treatment
- remove all brand identity

The goal is:

- still premium
- more understandable
- more trustworthy
- more sellable

## 13. Done definition

This refactor is successful when:

- homepage clearly sells Signature first
- diagnosis funnel works end-to-end in production
- CTA naming is consistent
- D.A.P. is understandable in plain Korean
- proof section exists
- Spark and Reserve are clearly subordinate to the main funnel, not competing equal first impressions
